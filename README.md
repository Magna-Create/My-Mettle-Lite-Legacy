# Gym App — Phase 1 Development Build

An offline-first React/TypeScript vertical slice based on the Gym App master specification.

## Run

```bash
npm install
npm run dev
```

## Verify

```bash
npm test
npm run build
```

## Android

```bash
npm run android:sync
npm run android:open
```

The working app name and app ID are placeholders because the final product name remains an open decision.

See `docs/PHASE_1_SCOPE.md` for the implemented boundary and intentional deferrals.

## Source of truth

The authoritative Markdown specification and structured JSON index are retained in `docs/spec/`.
